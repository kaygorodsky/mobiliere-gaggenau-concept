# MOBILIERE / GAGGENAU — design concept

Static homepage design preview. HTML, CSS and browser JavaScript; no database or build step.

Deploy `main` from the repository root using GitHub Pages. All images and fonts are local in `assets/`.

This is a design prototype. Catalogue, product, article and project links open the existing gaggenau.su website. Selection is browser-local and does not send enquiries automatically. See README-RU.txt for deployment instructions and current limitations.
