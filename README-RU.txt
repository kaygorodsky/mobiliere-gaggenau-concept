GAGGENAU / MOBILIERE — самостоятельный концепт сайта
Экспорт: 3 ноября 2026. Соответствует опубликованной версии 19.

РАЗМЕЩЕНИЕ НА ДОМЕНЕ
1. Распакуйте ZIP.
2. Загрузите index.html, все файлы .css/.js и папку assets в корень сайта
   (обычно public_html, www или htdocs). index.html должен быть прямо в корне.
3. Включите HTTPS на домене.
4. Откройте https://ваш-домен/ и проверьте переключение коллекций, поиск и подбор.

Не требуется: база данных, PHP, Node.js на сервере, npm, сборка, API-ключи,
учётная запись ChatGPT или специальный сервер приложений.
Подходит обычный статический хостинг с HTML/CSS/JavaScript.
Сервер должен отдавать .js с MIME text/javascript либо application/javascript,
.css — text/css, .woff2 — font/woff2. Не заменяйте запросы к этим файлам HTML-страницей.
Для размещения на отдельном домене специальные правила перенаправления не нужны.

ЛОКАЛЬНЫЙ ПРОСМОТР
Двойной щелчок по index.html (file://) не подходит: браузер может блокировать
JavaScript-модули. Откройте через локальный HTTP-сервер, например, при установленном Python:
  python -m http.server 8080
Затем откройте http://localhost:8080/.
Python нужен только для такого локального просмотра, на хостинге он не требуется.

ЧТО ВХОДИТ
Финальная главная страница, анимации, локальные изображения, логотип и шрифты,
поиск по локальной подборке, подбор моделей, модальные окна.
Старые страницы с предложениями дизайна в экспорт не включены.

ДАННЫЕ И ОГРАНИЧЕНИЯ
- Серверной базы данных и административной панели нет.
- Модели для поиска/подбора находятся в product-data.js; это статические данные.
- Названия, цены, описания и ссылки меняются вручную в HTML/JS.
  Цены и наличие не синхронизируются с исходным магазином.
- Черновик подбора сохраняется через localStorage только в браузере посетителя.
  Это не серверная БД; между браузерами/устройствами и доменами он не переносится.
- Автоматической отправки заявок, CRM, заказа/оплаты и реального бронирования визитов нет.
- Подборку можно скопировать и вручную отправить консультанту в Telegram.
- Автоматическое копирование работает при разрешении браузера на HTTPS/localhost;
  предусмотрен вариант ручного копирования.
- Каталог, карточки моделей, статьи, проекты и информационные страницы открывают
  внешний gaggenau.su. В архиве нет копии всего магазина.
- Ссылки Telegram и телефон используют текущие контакты MOBILIERE.
- Изображения и шрифты загружаются локально из assets. Внешних CDN и runtime-зависимости
  от ChatGPT для работы макета нет.
- Это дизайн-концепция, а не полноценная система интернет-магазина.

ОСНОВНЫЕ ФАЙЛЫ
index.html — контент и структура главной страницы.
app.js — взаимодействия, анимации, коллекции, поиск и подбор.
product-data.js — локальный набор моделей.
recommend.js, collection-state.js — логика подбора и переключений.
styles.css, dark.css, typography.css, overlap.css, interaction.css — оформление.
assets/ — локальные фотографии, логотип, шрифты.

Внутри нет .git, служебной конфигурации хостинга Sites, ключей и токенов.
SHA256SUMS.txt позволяет проверить целостность файлов.
